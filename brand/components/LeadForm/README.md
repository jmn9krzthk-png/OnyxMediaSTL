# LeadForm
Labeled fields for the booking form, with an error state that says how to fix it.

- **You provide:** a `<label for>` on every input. Required fields: name, email, company. Optional: phone, website, trade, service, budget, timeline, message.
- Ask **trade** ("HVAC, plumbing, roofing…") and **number of trucks** to qualify home service leads.
- Errors pair the `danger` border with a sentence ("Add a phone number so Max can call you back").
- The submit is a primary Button: "Send and book my call".
