# Logo
The Onyx Media wordmark, primary on light grounds and reversed on onyx.

- **You provide:** the ground. Use the reversed file on `bg` (Onyx), the primary file on `bg` (Daylight).
- **Size:** min 120px wide; in the site header, 132–160px wide.
- **Clear space:** the height of the O on all sides.
- **Don't:** place it on `amber`, recolor it, or scale it unevenly.
