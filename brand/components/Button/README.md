# Button
Square-cornered buttons. Amber primary for the one action that matters, outlined secondary, and a text link.

- **Primary** (`ox-btn ox-btn--primary`): "Book a Free Strategy Call" only, plus form submits. One per view. Ends with the play triangle.
- **Secondary** (`ox-btn ox-btn--secondary`): "See Our Work" and other second choices.
- **Text** (`ox-btn ox-btn--text`): inline "See the full case study" links.
- **You provide:** an `<a>` or `<button>` and its label. Labels are verbs and say what happens. Don't use "Learn more" or "Click here".
- Text on amber is always `on-amber`. On phones, stack buttons full width.
